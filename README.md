# FUE Hair Transplant Singapore: ad landing page

A single, fast, static landing page for FUE Malaysia's Singapore hair transplant offer. Its layout and section order follow the framer.com homepage, restyled as a clean white page with minimal motion (client request, 9 Oct 2026). All content, photos and videos come from https://www.fuemalaysia.com/hair-transplant-singapore/.

## Preview locally

From this folder, run one of these:

```bash
python3 -m http.server 8080        # then open http://localhost:8080
# or
npx serve .                         # then open the URL it prints
```

You need to use a local server rather than double-clicking `index.html`, because the 3D hero loads as an ES module.

## What's inside

```
index.html                 the page (generated by tools/build.py; edit build.py, then rebuild)
assets/css/style.css       design tokens and every style
assets/js/main.js          plain JS, no libraries: 0.2 s first-view fades, mobile menu, FAQ, gallery expand, video modal, WhatsApp form
archive/v2-dark-motion/     the previous dark, animated version (GSAP, Lenis, Three.js); not loaded, not in the site zip
assets/img/                every clinic image, as optimised WebP (+ -sm 480px variants)
tools/manifest.py          single source of truth: every asset, its original URL, alt text and caption
tools/process.py           downloads -> WebP conversion (needs assets/orig/, not shipped in the zip)
tools/build.py             builds index.html from the manifest and the copy
tools/wheel.py             makes the uniform, pin-free Step 03 results-grid crops (assets/img/wheel-*.webp)
tools/inventory.py         writes ASSET_INVENTORY.md
tools/verify.py            Playwright check: console errors, horizontal overflow, overlap, screenshots
screens/                   screenshots at 1440 and 390 px, plus side-by-side comparisons with framer.com
ref/                       framer.com reference screenshots (for comparison only, not used on the page)
ASSET_INVENTORY.md         every original image and video, and where it is used now
BUILD_PROMPT.md            a full prompt for Claude Code to rebuild or edit this page
```

## Rebuild after editing copy

```bash
python3 tools/wheel.py && python3 tools/build.py && python3 tools/inventory.py
python3 -m http.server 8765 &  python3 tools/verify.py     # optional QA (needs: pip install playwright && playwright install chromium)
```

## Deploy

Upload the folder (without `tools/`, `ref/`, `screens/` and `research/` if you like) to any static host, such as Vercel, Netlify or Cloudflare Pages. No build step or server is needed.

## Before going live

- The lead form opens WhatsApp with a pre-filled message. To capture leads in a CRM, or to fire Google Ads or Meta conversion events, add your tracking snippet and hook into the form `submit` handler in `assets/js/main.js`.
- Ask Dr Inder to approve the medical wording, and check the claims listed in the report (prices, "up to 70% cheaper", "over 100,000 successful procedures", and the year-end promotion banner).
